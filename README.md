# Standard Fullstack 

Fullstack starter using React, Express, MongoDB.

## Setup
1. in your terminal go to where you want to clone the starter and run - git clone https://github.com/Racksoup/StandardFullstack
2. in your terminal paste in - cd StandardFullstack; npm install; npm run clientinstall; npm run dev

to connect the database uncomment a few lines in server.js and add a .env file (similar to the sample.env file) with your mongoDB configs  
usually i host the website on render by linking it with my github account
